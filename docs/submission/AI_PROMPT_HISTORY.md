## 2. 三条完整 Prompt 链

### 链 A：从线性层列表到真实 ONNX 网络结构图

- 核心意图：指出颈部存在跨层输入，要求把顺序列表升级为可拖动、可点击的二维拓扑。
- 上下文约束：使用仓库内真实 `yolo11n.pt`/ONNX 数据；连接关系不能照论文手画；参考 SVG 只用于排布。
- AI 建议：从 ONNX 的 `/model.<N>/` 前缀聚合模块，解析外部输入张量，得到真实连边；用 SVG + 指针事件实现缩放、平移、节点拖动。
- 落地提交：`110cdfa`、`eb493c6`。

## 4. 真实性边界

- 本文档只声称“这些消息曾出现在本地 Codex 会话中”，不声称评审者可以从公开互联网独立重新打开原会话。

- 对话中的 AI 方案并非全部一次成功。导出内容保留了“根因定位 → 修补 → 构建 → 无头浏览器验证 → 再修复”的过程，未删除失败步骤。
- 仓库提交是最终事实来源：如果对话摘要与代码冲突，以当前仓库和探针输出为准。

## 第 2 轮：结构图拖拽与箭头 Bug

### 用户 Prompt（原文）

> 我希望修复几个小问题。在YOLOv11网络结构图模块界面中，当我尝试拖动结构图时，总是会把结构图上的文字内容选择出来(然后弹出是否要复制的选项)，我不知道这是为什么，请你尝试帮我解决一下。其次，模块图中的箭头十分粗糙，只是连线与三角形的组合，你能帮我更换成真正的箭头吗。

### AI 根因定位与修改

AI 在会话中给出的根因是：

> 问题确认：连边已经用了 `marker`，但默认三角 marker 会随线宽放大，跳连上显得又大又钝；文字选中则是因为 SVG 文本仍参与原生选择。接下来我会换成带圆角、独立尺寸的多状态箭头，并在拖拽时彻底禁用文本选择与原生拖拽。

实际修改：

- `.graphview` 与 `.graphview text` 设置 `user-select: none`，文本设置 `pointer-events: none`；
- `onPointerDown`/`onPointerMove` 调用 `preventDefault()`，并清除已有选区；
- 根容器增加 `onDragStart={() => preventDefault()}`；
- 旧填充三角形改为开放式圆角箭头 `M 2.5 2.5 L 10 6 L 2.5 9.5`；
- 使用 `markerUnits="userSpaceOnUse"` 固定尺寸，避免缩放时箭头变粗；
- 保留默认、上游、下游、跳连四种状态色。

### AI 最终回复（原文节选）

> **已修复**
>
> - 拖拽时选中文字：在 `src/viz/GraphView.jsx:119` 阻止了指针事件的默认选择行为，并在 `src/styles.css:319` 为结构图及 SVG 文本禁用了文本选择。现在拖动背景或节点不会再选中文字，也不会弹出复制提示。
> - 箭头样式：在 `src/viz/GraphView.jsx:176` 将原来的三角形箭头替换为圆角开放式箭头，并保留了默认、上游高亮、下游高亮、跨层跳连四种配色状态。
> - 已验证架构图/依赖图切换、节点点选、节点拖动、适应窗口复位。实际鼠标拖拽期间选区保持为空，控制台无错误。

> 说明：该修复与因果回溯在同一次代码迭代中落地，最终被合入提交 `78f9baf`；提交标题只写了因果回溯，但 diff 中保留了上述 CSS 与 marker 改动。

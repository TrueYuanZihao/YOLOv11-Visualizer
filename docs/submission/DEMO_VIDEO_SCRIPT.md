# 演示视频录制脚本

目标时长：7 分 20 秒  
规格：MP4，H.264，1920×1080，30 fps，含旁白  
硬性要求：至少 2 分钟真实 AI 协同过程复现

## 录制前准备

1. 以 1920×1080 分辨率打开项目，浏览器缩放 100%。
2. 先运行 `npm run dev`，确认模型已完成一次前向。
3. 打开 IDE，保留 3 个核心对话窗口或可搜索的历史 Prompt：
   - 网络结构图 / 架构图
   - 检测框因果回溯
   - 新手引导与 Bug 修复
4. 准备一个空白终端，用于展示 `npm ci`、`npm run build` 和一个探针命令。
5. 关闭通知、聊天软件和包含隐私信息的窗口。

## 时间轴

### 00:00–00:35 开场：问题与定位

画面：项目主界面，鼠标缓慢掠过左中右三栏。  
旁白：

> 这是一个面向 YOLO11 的交互式教学可视化工作坊。它不使用示意图，而是在浏览器里执行真实的 ONNX 前向，让学习者逐层观察特征、网络拓扑和检测框是如何产生的。

字幕：赛道：AI 驱动的高交互教育与可视化。

### 00:35–01:25 主工作台与单层特征

操作：点击左侧 `m3`，再点击 `m12`；切换 2D 特征图、通道网格、3D 特征金字塔；拖动伽马和通道滑块。  
旁白要点：真实张量、PCA、通道能量、悬停读数；改阈值只重算解码，不会重跑网络。

### 01:25–02:10 网络结构图

操作：打开“网络结构图”，切换架构图 / 依赖图，点选 `m12`，展示 6 条跨层跳连。  
旁白要点：581 个 ONNX 算子归并为 24 个模块，32 条连边全部来自计算图；布局是人工语义归档，但连边不是手画。

### 02:10–03:10 检测头与回放

操作：打开“检测头解剖”，依次展示锚点网格、候选框、NMS 抑制；回到主界面播放“前向回放”。  
旁白要点：2100 个锚点、三尺度网格、DFL 已解码、逐类 NMS、候选框如何变成最终框。

### 03:10–04:10 新手引导

操作：点击“新手引导”，展示高亮控件和“完成动作后才能继续”的约束，再进入“因果回溯”步骤。  
旁白要点：引导不是静态说明书，而是根据真实 UI 状态判断任务是否完成；支持上一步、跳过、退出和复习。

### 04:10–05:10 检测框因果回溯

操作：在“检测结果”中点击任意检测框；展示自动打开结构图、`m16/m19/m22` 三路头节点和金色上游路径；展示右侧 P3/P4/P5 锚点、同类分数和近似感受野缩略图；关闭结构图，展示主画布上的格点与感受野叠加。  
旁白要点：解码结果保留真实锚点编号；一个框对应一个直接预测锚点，另外两个尺度显示同位置投影；感受野按 4×stride 估算，并在界面和文档中明确标注。

### 05:10–07:10 AI 协同过程复现（必须保留 2 分钟）

这一段必须录制真实 IDE 对话，而不是项目页面。

建议选择“检测框因果回溯”作为案例：

1. 展示用户原始 Prompt：

   > 请你帮我实现功能：检测框因果回溯。点击任意检测框，自动高亮 P3/P4/P5 中命中的锚点，并在结构图中点亮 `m16/m19/m22 → 颈部 → 骨干` 的传播路径，同时在输入图上标出对应区域或近似感受野。

2. 展示 AI 对仓库的检索与修改建议：复用 `output0` 锚点编号，不重跑推理；建立统一因果模型；复用现有 `ancestorsOf` 路径算法。
3. 展示关键代码 diff：`src/model/causalTrace.js`、`src/viz/traceOverlay.js`、`src/viz/GraphView.jsx` 中的 `is-trace` 状态。
4. 展示 AI 如何用无头浏览器验证：点击检测框、检查三路头节点、验证 31 条上游边、检查控制台无错误。
5. 展示后续 Bug 修复 Prompt：

   > 因果回溯功能是否加载到了之前做的引导部分当中呢，请你确认一下。如果没有，请将其加入引导部分。

6. 展示修复结果：引导新增第 10 步，等待 `traceActive` 后才允许继续，并在离开步骤时清除回溯状态。

旁白要点：不是让 AI 直接“写一个页面”，而是给事实约束、验收条件和回归测试，让 AI 在可验证边界内迭代。

### 07:10–07:30 复现与收尾

画面：终端执行 `npm ci`、`npm run build`，回到 README 的 10 分钟复现路线。  
旁白：

> 仓库保留完整细粒度提交历史和 Prompt 对照。模型、WASM 和示例图片全部本地化，无需 API Key。按 README 的十分钟路线即可从空环境复现。
